About the Arithmetic Lab

The LEGv8 Arithmetic Lab is an interactive educational application designed to explore how computers perform arithmetic at the binary level.

Inspired by ARM and LEGv8 computer architecture, this project demonstrates binary multiplication, unsigned division, register behavior, and IEEE 754 floating-point representation.

Explore the Simulators

  • Floating-Point Visualizer: Examine IEEE 754 binary representations, exponent calculations, and differences between 32-bit and 64-bit precision.
  • Binary Multiplication: Step through multiplication using binary shifts and addition.
  • Binary Division: Explore binary long division using shifting, comparison, and subtraction.

Technologies Used

Python, JavaScript, HTML5, CSS3, pytest, and Git.

This application demonstrates arithmetic algorithms inspired by ARM/LEGv8 architecture. It is not a complete processor emulator and does not execute LEGv8 assembly instructions.
